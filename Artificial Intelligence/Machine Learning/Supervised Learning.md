# Supervised Learning
지도 학습(Supervised Learning)에서 알고리즘에 주입하는 훈련 데이터에는 레이블(label)이라는 원하는 답이 포함된다.지도학습은 새로운 데이터들의 레이블을 예측하는 모델 함수를 만드는데에 주 목적을 둔다. 

스팸 필터와 같은 분류(Classification)이 전형적인 지도학습의 예시이다. 스팸 필터는 많은 메일 샘플과, 이들이 스팸인지 아닌지에 대한 정보를 토대로 새 메일을 어떻게 분류할지 학습한다.

또한 예측 변수(predictor variable)이라 부르는 특성(feature)을 사용해 중고차 가격 같은 타겟 수치를 예측하는 것(regression)도 지도 학습의 예시이다. 이 시스템 훈련을 위해서는 예측 변수와 레이블(중고차 가격)이 포함된 중고차 데이터가 필요하다.

# WCAG
Web Content Accessibility Guidelines(WCAG, 웹 콘텐츠 접근성 지침)이란 W3C가 발행하는 웹 접근성 국제 표준이다. 시청각, 운동, 인지 장애가 있는 사용자도 웹 콘텐츠를 이용할 수 있게 만드는 방법들이 규정되어있다.

## 4대 원칙 (POUR)
* Perceivable(인식의 용이성)
	* 대체 텍스트가 있어야 함.
	* 자막이 있어야 함.
	* 단순 색상만으로 정보 전달이 되어서는 안됨.
	* 배경과 글자에 대비가 분명해야함.
* Operable(운용의 용이성)
	* 키보드만으로도 모든 기능 조작이 가능해야 함.
	* 포커스를 표시해야함.
	* 터치 대상은 최소 크기가 보장되어야 함.
* Understandable(이해의 용이성)
	* 일관된 네비게이션 구조를 가져야 함.
	* 명확한 레이블이 있어야 함.
* Robust(견고성)
